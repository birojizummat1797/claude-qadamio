# PM taklif va tavsiyalari — diagnostika metodologiyasi (2026-10-05)

Holat: **PM TAKLIFI** (qaror emas). Founder: "ikkalangni eshitgandan so‘nggina qaror qabul qilaman".
Manba: PM’ning Founder topshirig‘iga javobi (ikki xabar), Founder orqali yetkazilgan.
Claude tahlili: `docs/reviews/2026-10-05-methodology-deep-analysis.md`.

## PM’ning asosiy g‘oyasi
Qadam "senga mana shu kasb mos" testi emas: avval insonni tushunish → potensialni dalil bilan ajratish → qiziqish, qadriyat, ish uslubi, real sharoitni qo‘shish → shundan keyin mos yo‘llar. Zanjir: Potensial → Qiziqish → Afzalliklar → Ish uslubi → Qadriyatlar → Real imkoniyat/cheklovlar → Dalillarni birlashtirish → Mos yo‘nalishlar → Nega aynan ular → Keyingi rivojlanish yo‘li.

## 14 band (qisqacha)
1. **Qadam nima qiladi:** odamni kasbga majburlamaydi; avval o‘rganadi. Ustuvor qadriyat — yolg‘on yo‘q; dalil yetmasa "yetarli dalil yig‘ilmadi".
2. **Potensial va qiziqishni aralashtirmaslik:** signal turlari — Potential/Ability, Interest, Preference/Work style, Values, Readiness/Reality; har savol qaysi signalni o‘lchashi ko‘rsatiladi.
3. **Performance evidence:** faqat self-report bilan qobiliyat aniqlanmaydi; katalog bo‘yicha mini-topshiriqlar (data: jadvaldan xulosa; dasturlash: mantiq/kod muammosi; UI/UX: qulay variant; copywriting: aniqroq matn). "Yoqtiraman" ≠ "bajara oldim".
4. **Diagnostic integrity check:** juda tez javob, bir xil pattern, qarama-qarshi javoblar, ortiqcha "Bilmayman", topshiriqlarda tasodifiy javob — aniqlansa soxta tavsiya berilmaydi; foydalanuvchi asossiz ayblanmaydi.
5. **"Bilmayman" semantikasi:** 0 ham, minus ham emas — "dalil yo‘q / o‘lchanmagan".
6. **Tavsiya mantiqi:** "bitta haqiqiy kasbingiz" emas — "mavjud dalillar asosida eng kuchli yo‘llar"; Potential + Interest + Preference + Readiness birga; signal yetmasa ishonch pasayadi yoki tavsiya berilmaydi.
7. **1–5 qoidasi:** 5 — maksimum, majburiy emas; thresholdga yetmasa halol no-match; to‘ldirish taqiqlanadi.
8. **Savol sifati:** sodda, qisqa, jargonsiz, bir ma’noli, yashirin "to‘g‘ri javob"siz, ijtimoiy ma’qul javobga majburlamaydigan, kasbga yetaklamaydigan.
9. **Mapping:** Savol → Signal → Signal turi → Dalil turi → Qaysi kasbga ta’sir → Vazn/asos → Ishonchlilik xavfi. Qarorga ta’sir qilmaydigan savol o‘chiriladi.
10. **Hozircha kodlamaslik:** metodologiya → signal taksonomiyasi → matritsa → ishonchlilik modeli → performance rejasi → scoring → tavsiya modeli → no-match → 5–10 real test → kalibrlash → keyin kod.
11. **Real test:** 5–10 kishi; tushundimi, variantlarni farqladimi, "to‘g‘ri javob" qidirdimi, o‘zini tanidimi, sabablarni tushundimi, hayotiga mosmi.
12. **Sintetik simulyatsiya** aniqlik isboti emas; haqiqiy validatsiya — real odamlar + real natija.
13. **Yakuniy maqsad:** intelligence system; Potential → Career → Education → Skills → Practice → Employment → Growth; inson o‘zgaradi — qayta o‘rganiladi. Ikigai asos emas; o‘z metodologiyasi.
14. **Market intelligence:** tavsiyadan keyin har kasb uchun: bugungi bozor, talab dinamikasi, ish beruvchilar, geografiya/remote, kirish talablari, ko‘nikmalar, AI ta’siri, xavflar, 3–5 yillik kutilma, kelajak ko‘nikmalari. Bozor potensialni bekor qilmaydi. Manbalar birlamchi/autoritet; prognoz "prognoz" deb belgilanadi. Natija — decision intelligence: sabablar, dalillar, bozor, kutilma, xavf, kerakli ko‘nikmalar, boshlashning real yo‘li.

PM yakuniy formulasi: INSONNI TUSHUNISH → POTENSIAL → MOSLIK → REAL SHAROIT → BOZOR → DALILLARNI BIRLASHTIRISH → ASOSLI YO‘L → HARAKAT → NATIJANI KUZATISH → QAYTA O‘RGANISH.
